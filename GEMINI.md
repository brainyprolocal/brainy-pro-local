# brainy-pro-local — Agent Rules

## Deployment Workflow

- **Always push to GitHub after making changes.** Do not ask for permission — just commit and push to `origin main` as part of completing any task.
- **Never start a local dev server** (e.g. `npm run dev`, `next dev`, etc.) for verification. This project is connected to Vercel, which auto-deploys on every push to `main`. Use the live Vercel deployment for verification instead.
- Use descriptive, conventional commit messages (e.g. `feat:`, `fix:`, `chore:`).
